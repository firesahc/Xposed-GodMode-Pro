## 发布冻结条件

在同一个最终候选 SHA 上完成以下事项前，不递增为 6.8.1、不打 tag：

1. 增加并运行备份 V1 导入导出、旋转/迟到回调和 Recycler 生命周期 instrumentation。
2. 在 LSPosed 目标宿主验证创建、修改、删除、普通列表、Recycler 与图片替换。
3. 验证 Activity 返回/旋转、目标应用重启以及 system_server/Binder 重启恢复。
4. 使用正式 6.8 规则和备份执行原位加载、导入、重复恢复与图片完整性检查。
5. 将 Debug APK、AndroidTest APK、设备日志和结果绑定到同一候选 SHA。

未复现问题不能驱动新的稳定线架构改写。设备无法执行的项目保持 `BLOCKED` 或
`NOT_RUN`，不得用编译或 JVM 结果替代。
